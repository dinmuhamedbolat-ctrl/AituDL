# Canvas Deadline Assistant Bot 🤖

Telegram-бот для отслеживания дедлайнов ваших заданий в Canvas LMS. Получайте уведомления ровно за 3 дня до завершения работы.

## 🎯 Основные возможности

- 📅 Интеграция с Canvas LMS через iCal-фиды
- ⏰ Автоматические уведомления за 3 дня до дедлайна
- 🔄 Проверка календаря каждый час
- 💾 Сохранение данных в SQLite
- 🛡️ Обработка ошибок и надежность

## 📋 Требования

- Python 3.10+
- Telegram аккаунт
- Bot Token от @BotFather

## 🚀 Установка

### 1. Клонируйте репозиторий или создайте папку проекта

```bash
mkdir canvas-bot
cd canvas-bot
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

### 3. Создайте файл конфигурации

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и добавьте ваш Bot Token:

```
BOT_TOKEN=ваш_токен_от_botfather
```

### 4. Получите токен бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в файл `.env`

## 🏃 Запуск бота

```bash
python main.py
```

```
==================================
```

## 📖 Как использовать бота

### Команды

- `/start` - Запуск бота и приветствие
- `/help` - Справка по использованию
- `/set_link [URL]` - Сохранить ссылку на iCal-фид из Canvas
- `/check` - Посмотреть ближайшие дедлайны
- `/status` - Проверить статус подписки

### Получение ссылки на iCal-фид

1. Откройте [Canvas LMS](https://canvas.instructure.com)
2. Перейдите в **Календарь**
3. Найдите кнопку **Calendar Feed** или подобное
4. Скопируйте ссылку (она должна заканчиваться на `.ics`)
5. Отправьте на бота: `/set_link [ссылка]`

**Важно:** Убедитесь, что календарь имеет статус "Public" или "Доступно для ссылки"

### Пример использования

```
Пользователь: /start
Бот: [отправляет приветствие]

Пользователь: /set_link https://canvas.instructure.com/feeds/calendars/user123.ics
Бот: ✅ Ссылка успешно сохранена!

Пользователь: /check
Бот: [показывает ближайшие дедлайны]

[через 3 дня до дедлайна]
Бот: ⏰ НАПОМИНАНИЕ ОБ ДЕДЛАЙНЕ
     📌 Задание: Math Homework
     ⏳ Дедлайн: 25.04.2026 23:59
     ⌛ Осталось: 3 дня
```

## 🔧 Технический стек

- **aiogram 3.x** - асинхронная библиотека для работы с Telegram Bot API

- **python-dotenv** - загрузка переменных окружения

## 📊 Как работает проверка дедлайнов

1. **Каждый час** бот запускает проверку
2. **Для каждого пользователя:**
   - Скачивает iCal-фид с Canvas
   - Ищет события с дедлайнами
   - Проверяет, есть ли дедлайны за 71-72 часа (ровно 3 дня)
3. **Если найдены события:**
   - Отправляет уведомление с названием задания и точным временем
   - Записывает информацию в лог

## ⚙️ Настройка интервала проверки

Чтобы изменить интервал проверки дедлайнов с 1 часа:

Откройте `main.py`, найдите функцию `scheduler_init()` и измените:

```python
scheduler.add_job(
    check_deadlines,
    'interval',
    hours=1,  # Измените это число (например, hours=24 для ежедневной проверки)
    id='check_deadlines',
    name='Проверка дедлайнов',
    replace_existing=True
)
```

## 🐛 Решение проблем

### Бот не запускается

**Проблема:** `ValueError: BOT_TOKEN не найден`

**Решение:**
1. Создайте файл `.env` в папке проекта
2. Добавьте: `BOT_TOKEN=ваш_токен`
3. Перезапустите бота

### Команда /set_link не работает

**Проблема:** Бот отвечает "Ошибка валидации ссылки"

**Решение:**
- Убедитесь, что ссылка начинается с `http://` или `https://`
- Убедитесь, что ссылка содержит `.ics`
- Проверьте, что календарь доступен (статус "Public")

### /check показывает ошибку загрузки

**Проблема:** "Ошибка при загрузке календаря"

**Решение:**
- Проверьте интернет соединение
- Убедитесь, что ссылка все еще действительна
- Попробуйте повторить через минуту
- Проверьте логи в `bot.log`

### Уведомления не приходят

**Проблема:** События есть, но уведомлений нет

**Решение:**
- Используйте `/check` для проверки загрузки календаря
- Проверьте, что дедлайны действительно в будущем
- Посмотрите логи `bot.log` для уточнения статуса
- Бот отправляет уведомление только один раз (за 71-72 часа до дедлайна)

## 📝 Логирование

Все события записываются в файл `bot.log`:

- Запуск и остановка бота
- Сохранение ссылок пользователями
- Результаты проверки дедлайнов
- Отправленные уведомления
- Ошибки и исключения

Для просмотра логов:

```bash
# Linux/Mac
tail -f bot.log

# Windows
type bot.log
```

## 🔒 Безопасность

- Токен бота хранится в `.env` (добавьте в `.gitignore`!)
- Личные данные пользователей сохраняются локально в SQLite
- Нет передачи данных на сторонние сервисы (кроме Canvas LMS)

## 🔄 Поток данных

### Инициализация
```
main.py запуск
    ↓
config.py загрузка конфигурации
    ↓
database.py инициализация БД
    ↓
logger_setup.py настройка логирования
    ↓
APScheduler запуск
    ↓
handlers.py регистрация команд
    ↓
Bot polling запуск
    ↓
✅ Готов к работе
```

### Команда пользователя
```
Telegram сообщение
    ↓
handlers.py обработчик
    ↓
Валидация → parser.py
    ↓
Сохранение/получение → database.py
    ↓
Ответ пользователю → Telegram API
    ↓
Логирование → logger_setup.py
```

### Фоновая задача (каждый час)
```
APScheduler trigger
    ↓
main.py: check_deadlines()
    ↓
database.py: get_all_users()
    ↓
Для каждого пользователя:
    ├── parser.py: fetch_ical_events()
    ├── parser.py: get_deadline_events()
    └── Если есть события за 3 дня:
        ├── bot.send_message()
        └── logger.info()
```

## 🎯 Основные компоненты

### 1. **Bot Framework (aiogram)**
- Асинхронная работа с Telegram Bot API
- Обработка команд через декораторы
- Routing и middleware поддержка

### 2. **Database (SQLite + aiosqlite)**
- Локальное хранилище пользователей
- Асинхронные операции без блокировок
- Простая конфигурация

### 3. **Parser (icalevents + httpx)**
- Скачивание iCal-фидов
- Парсинг событий с датами
- Валидация дедлайнов

### 4. **Scheduler (APScheduler)**
- Фоновые задачи по расписанию
- Проверка дедлайнов каждый час
- Асинхронная работа

### 5. **Logging (встроенный logging)**
- Двухуровневое логирование (файл + консоль)
- Структурированный формат
- Простое отслеживание ошибок

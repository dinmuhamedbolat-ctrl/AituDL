# 🚀 Быстрый старт

## Предварительные требования

- Python 3.10 или выше
- pip (менеджер пакетов Python)
- Telegram аккаунт

## Пошаговая установка

### Шаг 1: Создайте Telegram бота

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/botfather)
3. Отправьте `/newbot`
4. Выполните инструкции:
   - Введите имя бота (например, "Canvas Bot")
   - Введите username (должно заканчиваться на `_bot`, например, `canvas_deadline_bot`)
5. **Скопируйте полученный токен** (выглядит как `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

### Шаг 2: Клонируйте/скачайте проект

```bash
# Перейдите в папку проекта
cd demobotaitu
```

### Шаг 3: Установите зависимости

```bash
# Установите все требуемые пакеты
pip install -r requirements.txt
```

Или более надежно (с виртуальным окружением):

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### Шаг 4: Создайте файл конфигурации

```bash
# Создайте .env файл (на основе примера)
copy .env.example .env  # Windows
# или
cp .env.example .env  # Linux/Mac
```

### Шаг 5: Добавьте токен бота

Откройте файл `.env` в текстовом редакторе и замените `YOUR_BOT_TOKEN_HERE` на ваш токен:

```
BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
```

### Шаг 6: Запустите бота

```bash
python main.py
```

Вы должны увидеть:

```
============================================================
🤖 Canvas Deadline Assistant Bot v1.0.0 запускается...
============================================================
✅ База данных готова
🚀 Планировщик APScheduler запущен
✅ Бот @YourBotName подключен и готов к работе!
============================================================
👂 Слушаю сообщения...
```

## ✅ Проверка работы

1. Откройте Telegram и найдите вашего бота (по username)
2. Отправьте команду `/start`
3. Вы должны получить приветственное сообщение

## 📚 Получение ссылки на iCal-фид

### Если вы используете Canvas LMS:

1. Откройте свой Canvas [canvas.instructure.com](https://canvas.instructure.com)
2. Нажмите на **Calendar** (Календарь)
3. Найдите кнопку **Calendar Feed** (обычно справа вверху)
4. Нажмите и скопируйте ссылку (будет примерно такой: `https://canvas.instructure.com/feeds/calendars/XXXXX.ics`)
5. Убедитесь, что календарь настроен как **"Public"** или "Доступно для ссылки"

### Отправьте ссылку боту:

```
/set_link https://canvas.instructure.com/feeds/calendars/XXXXX.ics
```

## 🧪 Тестирование

### Проверить загруженные дедлайны:

```
/check
```

Должны появиться ближайшие 5 дедлайнов из вашего календаря.

### Проверить статус:

```
/status
```

Должна показаться информация о сохраненной ссылке.

## 🛑 Остановка бота

Нажмите `Ctrl + C` в терминале.

## ⚙️ Настройка интервала проверки

По умолчанию бот проверяет дедлайны **каждый час**.

Чтобы изменить это на, например, каждые 24 часа:

Откройте `config.py` и измените:

```python
# Интервал проверки дедлайнов (в часах)
CHECK_INTERVAL_HOURS = 24  # Было 1
```

## 📋 Логи работы

Все события записываются в файл `bot.log`. Для просмотра:

```bash
# Windows
type bot.log

# Linux/Mac
cat bot.log

# Или отслеживайте в реальном времени:
tail -f bot.log
```

## ❌ Решение проблем

### Ошибка: `BOT_TOKEN не найден`

**Причина:** Файль `.env` не создан или не содержит токена.

**Решение:**
1. Создайте файл `.env`
2. Добавьте строку: `BOT_TOKEN=ваш_токен`

### Ошибка: `[Errno 2] No such file or directory: '.env'`

**Причина:** Файл конфигурации не в правильном месте.

**Решение:**
1. Убедитесь, что вы в папке `demobotaitu`
2. Создайте файл `.env` в этой папке

### Бот не отвечает на команды

**Проверьте:**
1. Токен правильный: `/me` в BotFather должен показать ваше имя бота
2. Интернет соединение в норме
3. Нет ошибок в `bot.log`

### Уведомления не приходят

**Проверьте:**
1. Ссылка на календарь сохранена: `/status`
2. В календаре есть дедлайны: `/check`
3. Убедитесь, что календарь **Public** (доступный по ссылке)
